Plug and play WordPress AI plugin connecting LocalWP or Live WordPress sites to Gabochie Design's 7-Figure Executive Agentic Engine.

== Description ==

This plugin provides:
1. Executive AI Studio embedded directly into your WordPress Admin.
2. Direct REST API endpoints connecting to Gemini 2.5 Flash.
3. Pan-African regional localization (Swahili, Amharic, Yoruba, French).
4. Ethical Cultural IP Artist Micro-Royalty Ledger tracking.
5. Gutenberg Block API v3 support for dynamic brand token generation.

== Quick Installation Guide ==

1. Log into your WordPress Admin Dashboard (http://your-site.local/wp-admin or live site).
2. Go to Plugins -> Add New -> Upload Plugin.
3. Select 'gabochiedesign-ai-studio.zip' and click 'Install Now'.
4. Click 'Activate Plugin'.
5. Access 'Gabochie AI Studio' directly from your left navigation menu!
