Automatically parses Yoast SEO recommendations for Posts and Pages and turns traffic lights 🟢 GREEN!

== Installation ==
1. Go to WP Admin -> Plugins -> Add New -> Upload Plugin.
2. Select yoast-seo-smart-autofixer.zip and click Install Now.
3. Click Activate Plugin.
4. Locate "Yoast Auto-Fixer ⚡" in your left Admin Sidebar or under Settings -> Yoast Auto-Fixer!
