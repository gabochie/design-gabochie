Enterprise-grade, AI-powered digital receptionist & maintenance mode suite for WordPress.

== Description ==
AI Agentic Maintenance Mode Pro turns scheduled downtime into an automated 24/7 client intake and lead generation pipeline.

= Features =
* HTTP 503 Maintenance Interceptor with auto-bypass for admins & whitelisted IPs.
* AI Executive Receptionist powered by Google Gemini API.
* Retrieval Augmented Generation (RAG) Memory over WP Posts & WooCommerce Products.
* Automated Lead Qualification (0-100 score) & Instant CRM Webhooks (HubSpot, Zapier).
* Instant Itemized PDF Quotation & Proposal Generator.

== Installation ==
1. Upload `ai-agentic-maintenance-mode-pro.zip` via WP Admin > Plugins > Add New > Upload.
2. Activate the plugin.
3. Configure Gemini API key in **AI Maintenance > AI Settings**.
4. Enable Maintenance Mode from the main dashboard!
